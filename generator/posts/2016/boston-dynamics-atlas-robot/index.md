# Boston Dynamics' Atlas Robot

![video thumbnail](https://i.ytimg.com/vi/rVlhMGQgDkY/hq720.jpg)

The latest version of Boston Dynamics' Atlas robot brings reality a bit closer to science fiction. The new model is slightly shorter than the previous and demonstrates an almost disturbing autonomy span.

In this video, the robot not only dispenses any human intervention, but seems to take all kinds of abuse like a champ. Of course, since they also have the ability to never forget, it's possible that in a few years, those folks may regret all that bullying :-)
