# The JavaScript Inferno

## Rob Conery

Now over a year old but still a very good presentation by Rob Conery on the madness of JS frameworks. It compares [Knockout](http://knockoutjs.com/ "knockout js"), [Backbone](http://backbonejs.org/ "backbone js"), [Angular](https://angularjs.org/ "angular js") and [Ember](http://emberjs.com/ "ember js") with examples.
